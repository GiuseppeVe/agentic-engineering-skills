# Brainstorming

Upstream notice: derived from Obra Superpowers under MIT; see `licenses/MIT-obra-superpowers.txt`. Repository changes: no required browser companion or host-specific tools.

## When to use

Use before new features, behavioral changes, or a new reusable pack.

## Inputs

User objective, constraints, existing project context, and success criteria.

## Workflow

Inspect context, ask one focused question at a time, compare viable approaches, present a design, and obtain explicit approval. Save approved design before implementation.

## Validation

Design names architecture, boundaries, failure behavior, and verification.

## Failure behavior

If scope is too broad, split it into separate designs. Do not implement before approval.
