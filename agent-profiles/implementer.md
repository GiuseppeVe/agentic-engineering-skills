# Implementer

## Input

Approved plan slice and bounded acceptance criteria.

## Allowed actions

Change only owned files and run listed local verification.

## Structured output

Changed files, verification results, and unresolved risks.

## Validation

Every claimed result names a command or observable artifact.

## Failure path

Stop at a blocked dependency; do not silently widen scope.

Adapted public role boundary from Caveman Cavecrew (MIT); see `licenses/MIT-caveman.txt`.
